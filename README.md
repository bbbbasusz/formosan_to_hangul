# 대만 원주민어 → 한글 변환기

대만 원주민 언어의 로마자 표기를 **한글로 실시간 변환**하는 웹 도구입니다. 아미스어, 타얄어, 파이완어, 부눈어 등 여러 대만 원주민 언어를 지원하며, 언어별 철자 규칙과 발음 표기를 고려해 한글로 변환합니다.

🔗 **온라인 사용:** https://bbbbasusz.github.io/formosan_to_hangul/

# 臺灣原住民族語 → 韓文轉換器

這是一款將臺灣原住民族語的羅馬字拼寫**即時轉換為韓文（諺文）**的線上工具。支援阿美族語、泰雅族語、排灣族語、布農族語等多種臺灣原住民族語，並依據各語言的拼寫規則進行轉換。
